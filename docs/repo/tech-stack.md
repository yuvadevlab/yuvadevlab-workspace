# 🛠️ Tech Stack & Versioning

This lab utilizes the latest stable versions of the following technologies to demonstrate modern industry standards.

## 🚀 Core Runtime & Languages

- **Node.js**: v22+ (LTS)
- **TypeScript**: v5.x (Strict Mode)
- **Python**: v3.12+ (for AI/ML services)

## 📦 Frameworks & Libraries

- **Frontend**: Next.js 14+ (App Router), React 18+
- **Backend (TS)**: NestJS 10+, Express
- **Backend (Python)**: FastAPI (High-performance async APIs), LangChain/LlamaIndex (RAG orchestration)
- **Validation**: Zod (TS), Pydantic (Python)
- **State/Cache**: Redis, PostgreSQL, MongoDB

## ⚙️ Infrastructure & DevOps

- **Monorepo Tooling**: Nx, pnpm Workspaces
- **Messaging**: Apache Kafka
- **Containerization**: Docker, Kubernetes
- **CI/CD**: GitHub Actions
- **Cloud**: AWS (Lambda, S3, EC2)

## 📏 Quality Standards

- **Versioning**: Semantic Versioning (SemVer) via Changesets.
- **Commits**: Conventional Commits (feat, fix, chore, etc.).
- **Linting**: ESLint + Prettier.
